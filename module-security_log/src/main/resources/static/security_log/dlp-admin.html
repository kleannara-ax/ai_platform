사업부부서사용
  • 여기 목록이 카카오톡 사용 승인 대장 등록·수정 때 사업부·부서 드롭다운으로 나옴 (사업부를 고르면 그 사업부의 부서만 표시)
  • 부서 이름은 DLP 유출 로그에 나오는 부서 이름과 글자까지 똑같이 넣어야 보고서에서 같은 사람으로 맞춰짐
  • 안 쓰는 사업부·부서는 삭제 대신 사용 끄기 → 드롭다운에서만 빠지고 이미 등록된 대장 값은 그대로
  • 이름을 바꿔도 이미 등록된 대장 값은 바뀌지 않음 · 추가·이름 바꾸기·사용 켜기/끄기는 관리자만

메일 알림 규칙

활성화규칙 이름보내는 날보내는 시각받는 사람 / 참조보낼 대기보냄실패마지막 실행
  • 대상 = 카카오톡 사용자 현황(승인 대장)의 '신청중' 건 · 같은 사람(부서+이름)은 신청 종료일이 가장 늦은 건 기준
  • 보내는 날이 되면 매일 정한 시각에 자동으로 보냄 · 신청 종료일이 같은 사람은 메일 1통에 모두 담아 보냄 (사람마다 규칙당 1번, 보낸 건은 다시 안 보냄, 실패한 건은 다음 날 다시 보냄)
  • 활성화 토글 = 켜면 정한 시각에 자동으로 보냄, 끄면 자동으로 보내지 않음 (규칙은 그대로 남고 [지금 보내기]는 가능) · 새 규칙은 켜진 상태로 만들어짐
  • 규칙을 만든 날보다 앞서 보내는 날이 지난 건은 보내지 않음 · 규칙 추가·수정·삭제·활성화·지금 보내기는 관리자만
  • 받는 사람·참조는 회사 메일만 (저장할 때 막고, 보낼 때 한 번 더 확인) · 받는 사람이 없으면 규칙을 켤 수 없음

규칙 추가

자리표시 (누르면 커서 위치에 넣음 · 보낼 때 실제 값으로 바뀜) · '사람마다' 자리표시가 들어간 줄은 인원 수만큼 반복 (예: 3명이면 3줄) · 제목의 {이름} 은 여러 명이면 '김철수 외 2명'
