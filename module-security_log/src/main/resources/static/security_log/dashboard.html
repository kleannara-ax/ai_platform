로그 업로드

시스템의 한 달치 접속·행위 로그 파일을 올리면, 그 시스템에 적용된 룰셋(공통 + 전용)으로 바로 분석합니다. 같은 월·시스템에 같은 파일은 다시 올릴 수 없습니다.

파일을 끌어다 놓거나 클릭해서 선택하세요
.xlsx .xls .csv .tsv .log .txt .json .out · 텍스트 최대 50MB, 엑셀 최대 20MB
전체 화면에서 업로드 상세 보기 / 검토
점검 매뉴얼 · 로그 검토자 점검 순서

원칙: 급한 것부터, 큰 그림 → 세부 순서로 봅니다.

1. 이번 달 상황 보기2. 볼 시스템 정하기3. 시스템 상세 검토 4. 월 마감위험도별 처리 시한주의할 점
1대시보드에서 이번 달 상황 보기
  1. 확인이 필요한 항목부터 봅니다 (할 일 목록).
    • 로그 미등록: 아직 안 올라온 시스템이 있는지
    • 기간 확인: 올라온 로그에 그 달 날짜가 빠졌거나 다른 달 로그가 섞였는지
    • 미검토 탐지: 위험 계정이나 탐지가 남은 시스템
    • 검토완료 가능: 위험이 없어 바로 마감할 수 있는 시스템
  2. 로그 업로드 현황: [업로드 완료]를 눌러 시스템별로 올라왔는지, 기간이 맞는지 확인합니다.
  3. 위험 접속 계정 TOP 10 / 특권 계정 활동: 이번 달 요주의 계정을 먼저 머리에 넣어 둡니다.
2어느 시스템부터 볼지 정하기
  • [접속·보안 로그] 목록에서 최고 위험도가 높은 업로드부터 엽니다: 심각 → 높음 → 보통
  • 위험도가 같으면 미검토 건수가 많은 것부터 봅니다.
3시스템 상세 화면 가장 중요
순서볼 곳확인할 내용
①업로드 정보대상 연월과 시스템이 맞는지, 파일이 맞는지
②룰별 탐지 건수 중 심각 높음실제 침해나 중요 변경일 수 있어 가장 먼저 봅니다
③① 접속 행위 분석위험 표시 계정(IP 제한 위반, 특권 계정, 외부 IP, 로그인 실패 5회 이상, 심야)을 봅니다. 탐지 건을 판단할 근거가 됩니다.
예: 로그인 실패 뒤에 정상 로그인했다면 단순 비밀번호 오입력
④룰별 탐지 건수 중 보통 낮음대부분 정상 업무입니다. 룰 단위로 확인하고 한 번에 처리합니다
⑤검토 현황 → 최종 검토완료미검토가 0건이 되면 ADMIN이 검토 의견을 쓰고 마감합니다
룰 하나를 처리하는 방법
  1. [로그 보기]로 그 룰의 로그를 훑어봅니다.
  2. 모두 같은 사유이면 [룰 일괄 검토]로 한 번에 처리합니다. 대상은 '미검토 건만'을 고릅니다.
  3. 수상한 줄이 섞여 있으면 그 줄만 먼저 줄 단위로 '이상징후 확인'으로 처리합니다. 나머지는 [룰 일괄 검토]에서 '미검토 건만'으로 '오탐'이나 '조치완료' 처리합니다.
검토 상태 고르는 기준
상태언제 쓰나
오탐정상 업무이거나 단순 실수로 확인됨 (예: 비밀번호 오입력, 승인된 작업)
조치완료문제가 있었지만 조치가 끝남 (예: 계정 회수, 정책 원복)
이상징후 확인실제 이상으로 보여 조치가 필요하고 아직 진행 중. 이 상태로 두면 나중에 다시 확인할 대상이 됩니다
4월 마감
  1. 대시보드 검토 현황에서 모든 시스템이 검토완료인지 확인합니다.
  2. [월 점검 결과 내보내기]로 엑셀을 받습니다.
  3. 엑셀 요약 시트의 검토자, 검토일, 승인자 서명란을 채워 ISMS 증적으로 보관합니다.
위험도별 처리 시한
위험도언제까지예
심각당일 확인, 침해사고 대응 절차 검토로그 삭제·감사 설정 변경, 랜섬웨어, 전체 개방
높음3일 이내, 담당자 소명관리자 계정·권한 변경, 인증 실패 다발, 허용 외 IP
보통월 점검 때 승인·작업 내역과 대조정책 변경, 데이터 다운로드
낮음추이만 확인, 반복되면 위험도 상향 검토심야 접근, 사용자 정보 변경

월말 점검과 별도로, 로그가 올라올 때마다 대시보드에서 심각·높음이 있는지는 바로 보는 것을 권합니다.

주의할 점
  • 룰별 탐지 건수 표는 탐지된 룰을 '건수가 많은 순'으로 먼저 보여주고, 0건 룰은 아래쪽 회색 줄로 위험도 순으로 보여줍니다. 위 순서대로 보려면 위험도 배지를 보고 골라야 합니다. 건수가 많은 룰이 보통·낮음일 때가 많습니다 (예: DLP 정책 변경 67건은 '보통').
  • 시스템 전용 룰이 초안인 시스템(설명에 '[샘플 확인 전 초안]' 표시)은 탐지 0건이 '이상 없음'이라는 뜻이 아닙니다. 이런 시스템은 ① 접속 행위 분석의 위험 계정을 더 꼼꼼히 봐 주세요. 실제 로그로 맞춘 시스템은 현재 홈페이지와 DLP 입니다.
