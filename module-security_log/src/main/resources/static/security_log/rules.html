룰셋 도움말 (눌러서 보기)
  • 여기 등록된 룰 중 사용인 룰로 로그를 분석 (DLP 점검 보고서도 같은 룰 결과로 작성)
  • 공통: 로그 유형이 같은 모든 시스템에 적용 · 전용: 그 시스템에만 적용
  • 키워드: 쉼표(,)로 구분한 단어 중 하나라도 있으면 일치 · 정규식: Java 정규식 · 모두 대소문자 무시
  • 내부 IP 외 접속: 줄에서 처음 나오는 IP 가 [관리 › 내부 IP 설정] 대역 밖이면 일치 · 패턴 칸 = 대상 줄 조건(정규식, 모든 줄은 .*)
  • 임계 건수: 파일 안에서 일치한 줄이 이 수 이상일 때만 탐지 (예: 로그인 실패 10회 이상)
  • 룰 변경은 이후 업로드·재분석부터 적용
룰 편집은 관리자(ROLE_ADMIN)만 가능 · 현재 조회만 가능
