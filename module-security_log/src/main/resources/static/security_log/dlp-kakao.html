카카오톡 사용 승인 대장

사업부부서이름신청 시작일신청 종료일신청 상태최신여부상태전자결재 문서번호사유
  • 전자결재로 승인되면 [등록] → 목록 맨 위 입력 줄에 바로 입력 후 [저장] (Enter = 저장, Esc = 취소, 신청 상태 = 신청중)
  • 사업부·부서 = 드롭다운에서 선택 (사업부를 고르면 그 사업부의 부서만 나옴) · 목록은 DLP 관리 > 사업부·부서 관리에서 추가·변경
  • 날짜 = 숫자 8자리만 입력하면 바로 적용 (20261001 → 2026-10-01) 또는 달력 버튼으로 선택
  • 정렬 = 신청 종료일이 늦은 순 (최신 먼저)
  • 상태·최신여부는 날짜로 자동 계산 (최신 = 같은 부서·이름 중 종료일이 가장 늦은 건)
  • [엑셀 내려받기] = 지금 화면의 거르기(상태·최신 건만·검색) 그대로 엑셀 파일로 저장 · 누구나 가능
