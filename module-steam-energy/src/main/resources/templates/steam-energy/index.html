스팀에너지관리 (module-steam-energy)

플랫폼 통합 백엔드 모듈. 프론트엔드 화면은 후속으로 연결합니다.

제공 REST API (/steam-energy-api)

  • GET/POST/PUT/DELETE /steam-energy-api/equipments — 스팀 설비 마스터
  • GET/POST/PUT/DELETE /steam-energy-api/prices — 시설별 단가(연/월)
  • GET/POST/DELETE /steam-energy-api/daily-usages — 일일 스팀 사용 실적

모든 API는 플랫폼 JWT 인증이 적용되며, 쓰기 작업은 메뉴 권한(STEAM_ENERGY_MGMT)이 필요합니다.
