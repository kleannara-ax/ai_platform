# 설비관리 - 기타설비 API

> **URL Prefix**: `/facility-api`  
> **인증**: JWT Bearer Token  
> **권한**: 메뉴 권한 기반 `@coreMenuService.hasMenuAccessByAuth(...)`

## 개요

기타설비는 에어컨과 정수기를 소화기와 동일한 관리 흐름으로 다룹니다.

- 목록 조회
- 상세 조회
- 등록/수정
- 삭제
- 대표 이미지 업로드/조회
- 점검 완료
- 점검 이력 추가/수정/삭제
- 건물/층/좌표/비고 관리

## 화면 URI

| 화면 | URI |
|---|---|
| 에어컨 관리 | `/facility/air-conditioners` |
| 정수기 관리 | `/facility/water-purifiers` |

## 역할/메뉴 권한

| 역할 | 접근 범위 |
|---|---|
| `ROLE_ADMIN` | 전체 |
| `ROLE_FACILITY_MANAGER` | 소방설비 + 기타설비 전체 |
| `ROLE_FIRE_MANAGER` | 소방설비만 |
| `ROLE_EQUIPMENT_MANAGER` | 기타설비만 |

| 메뉴 코드 | 설명 |
|---|---|
| `FIRE_MGMT` | 설비관리시스템 상위 메뉴 |
| `FIRE_EQUIPMENT_GROUP` | 소방설비 그룹 |
| `OTHER_EQUIPMENT_GROUP` | 기타설비 그룹 |
| `OTHER_AIRCON` | 에어컨 |
| `OTHER_WATER_PURIFIER` | 정수기 |

## 목록 조회

```http
GET /facility-api/air-conditioners?page=0&size=50&q=복지관&buildingId=1&floorId=2
```

### Query Parameters

| 이름 | 필수 | 설명 |
|---|---|---|
| `page` | N | 페이지 번호, 기본 `0` |
| `size` | N | 페이지 크기, 기본 `50` |
| `q` | N | 건물/층/종류/일련번호/비고 검색 |
| `buildingId` | N | 건물 ID |
| `floorId` | N | 층 ID |

## 등록/수정 요청

```http
POST /facility-api/air-conditioners
Content-Type: application/json
```

```json
{
  "equipmentId": null,
  "buildingId": 1,
  "floorId": 2,
  "equipmentType": "시스템",
  "manufactureDate": "2026-06-01",
  "replacementCycleYears": 10,
  "quantity": 1,
  "x": 12.34,
  "y": 56.78,
  "note": "비고"
}
```

- `equipmentId`가 없으면 신규 등록, 있으면 수정입니다.
- 신규 일련번호는 에어컨 `AC-000001`, 정수기 `WP-000001` 형식으로 자동 생성됩니다.

## 이미지 업로드

```http
POST /facility-api/air-conditioners/{id}/image
Content-Type: multipart/form-data
```

| 필드 | 설명 |
|---|---|
| `file` | 이미지 파일 |

- 최대 10MB
- `image/*` MIME만 허용
- 업로드 시 기존 대표 이미지는 삭제되고 1장만 유지됩니다.

## 점검 완료

```http
POST /facility-api/air-conditioners/inspect
Content-Type: application/json
```

```json
{
  "equipmentId": 1,
  "inspectionDate": "2026-06-09",
  "faulty": false,
  "faultReason": ""
}
```

- `inspectionDate` 생략 시 서버 기준 오늘 날짜로 저장됩니다.
- `faulty=true`인 경우 `faultReason`이 필요합니다.
- 동일 설비/동일 날짜의 중복 점검은 허용하지 않습니다.
- 점검 이력은 최신 12건만 유지합니다.
