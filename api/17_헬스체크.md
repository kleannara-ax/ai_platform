# 헬스체크 API (Health Check)

> **모듈**: app, module-ps-insp

---

## 1. 앱 헬스체크

| 항목 | 값 |
|------|-----|
| **URL** | `GET /api/health` |
| **인증** | 불필요 |
| **컨트롤러** | `HealthController` (app) |
| **용도** | Apache Reverse Proxy 상태 확인 |

### Response — `ApiResponse<Map<String, Object>>` (200 OK)

```json
{
  "success": true,
  "code": 200,
  "data": {
    "status": "UP",
    "timestamp": "2026-05-06T10:30:00",
    "application": "platform"
  }
}
```
