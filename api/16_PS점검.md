# PS 지분 검사 API (PS Inspection)

> **모듈**: module-ps-insp
> **권한**: 메뉴 접근 권한 `PS_INSP_MGMT` 기반 인가

---

## A. 검사 결과 API

> **URL Prefix**: `/ps-insp-api/inspections`
> **컨트롤러**: `PsInspectionApiController`

### 1. 검사 결과 저장 (JSON)

| 항목 | 값 |
|------|-----|
| **URL** | `POST /ps-insp-api/inspections` |
| **인증** | 필요 (메뉴 권한 `PS_INSP_MGMT`) |
| **Content-Type** | `application/json` |

### Request Body — `PsInspectionSaveRequest`

검사 결과 저장에 필요한 정보를 포함합니다 (matnr, lotnr, indBcd, totalCount, coverageRatio 등).

### Response — `ApiResponse<PsInspectionResponse>` (201 Created)

---

### 2. 검사 결과 저장 (Multipart: 이미지 포함)

| 항목 | 값 |
|------|-----|
| **URL** | `POST /ps-insp-api/inspections` |
| **인증** | 필요 (메뉴 권한 `PS_INSP_MGMT`) |
| **Content-Type** | `multipart/form-data` |

### Request Parts

| 파트명 | 타입 | 필수 | 설명 |
|--------|------|------|------|
| `metadata` | String (JSON) | O | `PsInspectionSaveRequest` JSON 문자열 |
| `originalImage` | MultipartFile | - | 원본 이미지 |
| `resultImage` | MultipartFile | - | 결과 이미지 |

### Response — `ApiResponse<PsInspectionResponse>` (201 Created)

---

---

### 4. 검사 결과 목록 조회 (페이징 + 필터)

| 항목 | 값 |
|------|-----|
| **URL** | `GET /ps-insp-api/inspections` |

| 파라미터 | 타입 | 필수 | 기본값 | 설명 |

### 5. 검사 결과 검색

| 항목 | 값 |
|------|-----|
| **URL** | `GET /ps-insp-api/inspections/search` |
| **인증** | 필요 (메뉴 권한 `PS_INSP_MGMT`) |

### Query Parameters

| 파라미터 | 타입 | 필수 | 기본값 | 설명 |
|----------|------|------|--------|------|
| `type` | String | - | `indBcd` | 검색 유형: `indBcd`, `lotnr`, `matnr` |
| `keyword` | String | O | - | 검색 키워드 |
| `page` | Integer | - | 0 | 페이지 번호 |
| `size` | Integer | - | 20 | 페이지 크기 (최대 100) |

### 호출 예시

```
GET /ps-insp-api/inspections/search?type=lotnr&keyword=LOT001&page=0&size=20
```

### Response — `ApiResponse<Page<PsInspectionResponse>>` (200 OK)

## B. MES 결과 전송 API

> **URL Prefix**: `/ps-insp-api/mes`
> **컨트롤러**: `PsInspMesController`

### MES에 검사 결과 전송

| 항목 | 값 |
|------|-----|
| **URL** | `POST /ps-insp-api/mes/send-result` |
| **인증** | 필요 (메뉴 권한 `PS_INSP_MGMT`) |
| **Content-Type** | `application/json` |

### Request Body — `PsInspMesSendRequest`

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `IND_BCD` | String | O | 개별 바코드 |
| `RST_VAL` | Integer | O | 검사 결과값 (ppm) |

### Request 예시

```json
{
  "IND_BCD": "25830J0069",
  "RST_VAL": 777
}
```

### 내부 처리

```
백엔드 → MES:
  GET https://mesdev.kleannara.com:444/mobile/saveDustInspectionResult.data
      ?IND_BCD=25830J0069&RST_VAL=777
```

### Response — `ApiResponse<PsInspMesSendResponse>` (200 OK)

`PsInspMesSendResponse` 필드:

| 필드 | 타입 | 설명 |
|------|------|------|
| `RS_CODE` | String | MES 응답 코드 |
| `RS_MSG` | String | MES 응답 메시지 |
