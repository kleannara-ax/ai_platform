# 소방 대시보드 / 지도 / QR API

> **모듈**: module-fire

---

## A. 대시보드 통계 API

> **URL Prefix**: `/fire-api/dashboard`
> **컨트롤러**: `FireDashboardController`

### 1. 소방시설 통계 조회

| 항목 | 값 |
|------|-----|
| **URL** | `GET /fire-api/dashboard/stats` |
| **인증** | 필요 |

### Response — `ApiResponse<Map<String, Object>>` (200 OK)

| 필드 | 타입 | 설명 |
|------|------|------|
| `extinguisherCount` | Long | 소화기 총 수 |
| `hydrantCount` | Long | 소화전 총 수 |
| `pumpCount` | Long | 소방펌프 총 수 |
| `receiverCount` | Long | 수신기 총 수 |
| `totalEquipment` | Long | 전체 장비 합계 |
| `buildingCount` | Long | 건물 수 |

### Response 예시

```json
{
  "success": true,
  "code": 200,
  "data": {
    "extinguisherCount": 150,
    "hydrantCount": 45,
    "pumpCount": 8,
    "receiverCount": 12,
    "totalEquipment": 215,
    "buildingCount": 10
  }
}
```

## B. 지도 API

> **URL Prefix**: `/fire-api/maps`
> **컨트롤러**: `MapController`

### 1. 건물별 도면 등록 층 목록 조회

| 항목 | 값 |
|------|-----|
| **URL** | `GET /fire-api/maps/building-floors` |
| **인증** | 필요 |

### Response — `ApiResponse<List<Map>>` (200 OK)

```json
{
  "success": true,
  "data": [
    {
      "buildingId": 1,
      "buildingName": "복지관",
      "floors": [
        { "floorId": 1, "floorName": "지하1층(B1)" },
        { "floorId": 2, "floorName": "1층" },
        { "floorId": 3, "floorName": "2층" }
      ]
    }
  ]
}
```

### 2. 층별 소방시설 데이터 조회 (도면 + 장비 좌표)

| 항목 | 값 |
|------|-----|
| **URL** | `GET /fire-api/maps/floor-data` |
| **인증** | 필요 |

### Query Parameters

| 파라미터 | 타입 | 필수 | 설명 |
|----------|------|------|------|
| `buildingId` | Long | O | 건물 ID |
| `floorId` | Long | O | 층 ID |

### Response — `ApiResponse<Map<String, Object>>` (200 OK)

| 필드 | 타입 | 설명 |
|------|------|------|
| `buildingId` | Long | 건물 ID |
| `buildingName` | String | 건물명 |
| `floorId` | Long | 층 ID |
| `floorName` | String | 층 이름 |
| `planImagePath` | String | 도면 이미지 경로 |
| `extinguishers` | List | 소화기 좌표 목록 `[{extinguisherId, x, y}]` |
| `hydrants` | List | 소화전 좌표 목록 `[{hydrantId, hydrantType, x, y}]` |

## C. QR 코드 API

> **URL Prefix**: `/fire-api/qr`
> **컨트롤러**: `QrController`

### 1. QR 이미지 생성 (PNG)

| 항목 | 값 |
|------|-----|
| **URL** | `GET /fire-api/qr/image` |
| **인증** | 불필요 (permitAll) |
| **Response Content-Type** | `image/png` |

### Query Parameters

| 파라미터 | 타입 | 필수 | 설명 |
|----------|------|------|------|
| `type` | String | O | 장비 유형: `ext`(소화기), `hyd`(소화전), `receiver`/`rcv`(수신기), `pump`/`pmp`(소방펌프) |
| `id` | String | O | QR 키 (예: `EXT-000001`) |

### 호출 예시

```
GET /fire-api/qr/image?type=ext&id=EXT-000001
```

### Response

QR 코드 PNG 이미지 바이너리 (240x240px)

---

### 5. 미등록 시리얼(QR 키) 생성

| 항목 | 값 |
|------|-----|
| **URL** | `GET /fire-api/qr/unregistered-serials` |
| **인증** | 필요 |

### Query Parameters

| 파라미터 | 타입 | 기본값 | 설명 |
|----------|------|--------|------|
| `extCount` | Integer | 0 | 생성할 소화기 QR 키 수 (최대 500) |
| `hydCount` | Integer | 0 | 생성할 소화전 QR 키 수 (최대 500) |
| `receiverCount` | Integer | 0 | 생성할 수신기 QR 키 수 (최대 500) |
| `pumpCount` | Integer | 0 | 생성할 소방펌프 QR 키 수 (최대 500) |

### 호출 예시

```
GET /fire-api/qr/unregistered-serials?extCount=5&hydCount=3
```

### Response — `ApiResponse<Map<String, Object>>` (200 OK)

| 필드 | 타입 | 설명 |
|------|------|------|
| `unregisteredExtSerials` | List\<String\> | 미등록 소화기 QR 키 |
| `unregisteredHydSerials` | List\<String\> | 미등록 소화전 QR 키 |
| `unregisteredReceiverSerials` | List\<String\> | 미등록 수신기 QR 키 |
| `unregisteredPumpSerials` | List\<String\> | 미등록 소방펌프 QR 키 |
