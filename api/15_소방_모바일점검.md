# 소방 모바일 점검 API (Mobile Inspection)

> **URL Prefix**: `/fire-api/minspection`
> **컨트롤러**: `MobileInspectionController`
> **모듈**: module-fire
> **설명**: QR 코드 스캔 기반 모바일 현장 점검용 API

---

## A. 소화기 모바일 점검

### 1. QR 키로 소화기 조회

| 항목 | 값 |
|------|-----|
| **URL** | `GET /fire-api/minspection/extinguishers/by-key` |
| **인증** | 필요 |

### Query Parameter

| 파라미터 | 타입 | 필수 | 설명 |
|----------|------|------|------|
| `key` | String | O | QR 키 값 |

### Response — `ApiResponse<Map>` (200 OK)

- **등록된 소화기**: `exists=true`, 소화기 상세 정보 포함
- **미등록 QR 키**: `exists=false`, 건물/층 목록 + 도면 매핑 옵션 포함 (현장 등록용)

---

### 2. ID로 소화기 조회 (최근 점검 이력 포함)

| 항목 | 값 |
|------|-----|
| **URL** | `GET /fire-api/minspection/extinguishers/{id}` |
| **인증** | 필요 |

### Response 주요 필드

| 필드 | 타입 | 설명 |
|------|------|------|
| `extinguisherId` | Long | 소화기 ID |
| `serialNumber` | String | 시리얼 번호 |
| `buildingName` | String | 건물명 |
| `floorName` | String | 층 이름 |
| `extinguisherType` | String | 소화기 종류 |
| `lastInspectionDate` | LocalDate | 최근 점검일 |
| `lastInspectorName` | String | 최근 점검자 |
| `lastIsFaulty` | Boolean | 최근 점검 고장 여부 |

---

### 3. 소화기 현장 등록

| 항목 | 값 |
|------|-----|
| **URL** | `POST /fire-api/minspection/extinguishers/register` |
| **인증** | 필요 |
| **Content-Type** | `application/json` |

### Request Body

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `qrKey` | String | O | QR 키 |
| `buildingId` | Long | O | 건물 ID |
| `floorId` | Long | O | 층 ID |
| `extinguisherType` | String | O | 소화기 종류 |
| `manufactureDate` | String | - | 제조일 (`yyyy-MM-dd`) |
| `inspectionDate` | String | - | 최초 점검일 |
| `inspectorName` | String | - | 점검자명 |
| `x` | BigDecimal | - | 도면 X 좌표 |
| `y` | BigDecimal | - | 도면 Y 좌표 |

### Response 주요 필드

| 필드 | 설명 |
|------|------|
| `extinguisherId` | 생성된 소화기 ID |
| `qrKey` | 할당된 QR 키 |
| `alreadyExists` | 이미 등록된 QR 키인 경우 `true` |

---

### 4. 소화기 모바일 점검 등록

| 항목 | 값 |
|------|-----|
| **URL** | `POST /fire-api/minspection/extinguishers/{id}/inspect` |
| **인증** | 필요 |
| **Content-Type** | `application/json` |

### Request Body

| 필드 | 타입 | 설명 |
|------|------|------|
| `isFaulty` | Boolean | 고장 여부 |
| `faultReason` | String | 고장 사유 |
| `inspectorName` | String | 점검자명 (미입력 시 로그인 사용자) |

> 같은 날 중복 점검 시 에러: "오늘 이미 점검을 완료했습니다."

### Response — `ApiResponse<Void>` (200 OK)

---

### 5. 소화기 이미지 업로드/조회

| URL | Method | 설명 |
|-----|--------|------|
| `/fire-api/minspection/extinguishers/{id}/image` | POST | 이미지 업로드 (multipart, 최대 10MB) |
| `/fire-api/minspection/files/extinguishers/{filename}` | GET | 이미지 파일 조회 |

---

### 6. 소화기 도면 데이터 조회

| 항목 | 값 |
|------|-----|
| **URL** | `GET /fire-api/minspection/extinguishers/mapdata` |
| **인증** | 필요 |

### Query Parameters

| 파라미터 | 타입 | 필수 | 설명 |
|----------|------|------|------|
| `buildingId` | Long | O | 건물 ID |
| `floorId` | Long | O | 층 ID |

### Response 주요 필드

| 필드 | 설명 |
|------|------|
| `planImagePath` | 도면 이미지 경로 |
| `items` | 소화기 좌표 목록 `[{extinguisherId, x, y}]` |

## B. 소화전 모바일 점검

### 1~6. 소화전 관련 API

소화기와 동일한 패턴이며, URL에 `hydrants`를 사용합니다.

| URL | 설명 |
|-----|------|
| `GET /fire-api/minspection/hydrants/by-key?key={qrKey}` | QR 키로 소화전 조회 |
| `GET /fire-api/minspection/hydrants/{id}` | ID로 소화전 조회 |
| `POST /fire-api/minspection/hydrants/register` | 소화전 현장 등록 |
| `POST /fire-api/minspection/hydrants/{id}/inspect` | 소화전 점검 등록 |
| `POST /fire-api/minspection/hydrants/{id}/image` | 이미지 업로드 |
| `GET /fire-api/minspection/files/hydrants/{filename}` | 이미지 파일 조회 |
| `GET /fire-api/minspection/hydrants/mapdata?buildingId=&floorId=` | 도면 데이터 조회 |

#### 소화전 등록 추가 필드

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `hydrantType` | String | O | `Indoor` 또는 `Outdoor` |
| `operationType` | String | O | `Manual` 또는 `Auto` |
| `locationDescription` | String | - | 위치 설명 |

> `Outdoor` 선택 시 `buildingId=99`, `floorId=99`로 자동 설정

## C. 수신기 모바일 점검

| URL | 설명 |
|-----|------|
| `GET /fire-api/minspection/receivers/by-key?key={qrKey}` | QR 키로 수신기 조회 |
| `GET /fire-api/minspection/receivers/{id}` | ID로 수신기 조회 |
| `POST /fire-api/minspection/receivers/register` | 수신기 현장 등록 |
| `POST /fire-api/minspection/receivers/{id}/inspect` | 수신기 점검 등록 |
| `POST /fire-api/minspection/receivers/{id}/image` | 점검 이미지 업로드 |
| `GET /fire-api/minspection/files/receivers/{filename}` | 이미지 파일 조회 |

#### 수신기 점검 Request Body

| 필드 | 타입 | 설명 |
|------|------|------|
| `items` | List | 체크리스트 항목: `[{key, label, result}]` |
| `inspectorName` | String | 점검자명 |
| `note` | String | 비고 |

체크리스트 `key` 값: `power`, `switch`, `transfer_device`, `zone_map`, `continuity_test`, `operation_test`
`result` 값: `NORMAL` 또는 `FAULTY`

> 같은 날 중복 점검 시 에러. 최근 12건만 보관.
