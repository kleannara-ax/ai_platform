CCKB 후면 색상 검사

색상 검사 탭에서 사진 1장을 업로드하면 이미지 전체 평균 L*, a*, b* 값을 자동 계산하고, 고정된 기준값(불러오는 중...)과 비교하여 정상 / 경계 / 불량으로 자동 판정합니다. 판정 결과는 검사 이력 탭에 검사번호와 함께 자동 기록되고, 기준값은 ⚙ 기준값 설정 탭에서 변경할 수 있습니다.

🔁 검사번호 -에 대한 재검사를 진행 중입니다. 사진을 업로드하고 판정을 실행하면 재검사 결과로 기록됩니다.

검사 이력 조회

검사 결과의 ΔL*/Δa*/Δb*, ΔE00은 모두 이 기준값과 검사 사진 측정값의 차이로 계산됩니다. 정상/불량 판정 조건도 이 탭에서 함께 변경할 수 있으며, 저장하면 이후 모든 판정에 즉시 적용됩니다. (기준값 수정은 공통코드 그룹 CCKB_PERM에 등록된 관리자만 가능하며, 서버에서 권한을 검증합니다. 변경 이력은 모두 감사 로그(standard_audit_log)에 기록됩니다.)
